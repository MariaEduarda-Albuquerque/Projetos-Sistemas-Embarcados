# Projetos - Sistemas Embarcados

Repositório de projetos práticos de sistemas embarcados desenvolvidos com Arduino durante meus estudos, organizados por pasta para facilitar navegação e demonstração.

## Sobre o repositório

Este repositório reúne projetos práticos de hardware e automação, com foco em:

- Praticar leitura de entradas digitais e controle de saídas
- Aplicar lógica condicional e temporização em sistemas físicos
- Manter um portfólio organizado de estudo e evolução

---

## Estrutura do Repositório

| Pasta | Conteúdo |
|---|---|
| `Botão com Lógica de Alternância/` | Interruptor toggle: um botão liga e desliga uma lâmpada alternadamente, usando contador e operador módulo |
| `Controle de com LED Dois Botões/` | Controle de lâmpada com dois botões independentes, aplicando lógica OU |
| `Semáforo Inteligente/` | Semáforo automatizado para carros e pedestres, com ciclo de tempo controlado por software |

---

## Como executar os programas

**Pré-requisito:** Arduino IDE instalado (ou acesso ao [Tinkercad](https://www.tinkercad.com/)).

```bash
# 1. Clone o repositório
git clone https://github.com/MariaEduarda-Albuquerque/Projetos-Sistemas-Embarcados.git

# 2. Acesse a pasta do projeto desejado
cd "Semáforo Inteligente"

# 3. Abra o arquivo .ino na Arduino IDE (ou recrie o circuito no Tinkercad)
```
